KDP V5 —— 全站 DeepSeek 单次用量与费用显示

本补丁实现：
1. 每一次真正调用 DeepSeek 后，都读取 API 返回的 usage；
2. 显示：
   - 本次总 Tokens
   - 输入 Tokens
   - 输出 Tokens
   - 缓存命中 Tokens
   - 缓存未命中 Tokens
   - 思考 Tokens（若API返回）
   - 使用模型
   - 本次估算人民币费用
   - 当前浏览会话累计请求数 / Tokens / 估算费用
3. 覆盖范围：
   - 专题调研
   - 多文献比较
   - 开裂诊断中的AI综合
   - 理论计算助手
   - 研究空白
   - AI科研智能体
   - 报告中心
   - 研究方向决策报告
4. 费用估算采用 DeepSeek 2026-08 官方公开人民币单价。
5. 实际扣费仍以 DeepSeek 控制台为准。
